# Night Light Slider

A GNOME Shell extension that adds a night light color-temperature slider to the
quick settings menu, directly under Brightness.

## Reason to be

Changing the night light on Ubuntu 26 is too many clicks:

Settings → Displays → Night Light → you are finally at the slider.

## What it does

- Adjust the slider to warm or cool the screen.
- Click the icon to toggle night light on and off. Adjusting while night light is off turns it back on.
- Adjusting previews the effect when the schedule has night light off.
- Hides on hardware that does not support night light.

## Requirements

GNOME Shell 50.

## Install

symlink from the gnome extension folder.
